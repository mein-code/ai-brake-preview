경계선은 내가.

AI가 파일을 바꾸고, 자료를 보내고, 호출을 반복하는 시대.
내가 원하지 않은 행동을 실행 전에 확인하는
개인용 안전장치를 만들고 있습니다.

이 페이지는 소개·설명용입니다. 방문하거나 버튼을 눌러도 기기가 보호되지는 않습니다.

01 · 규칙이 먼저

위험한 행동에 브레이크

AI가 스스로 허락하지 않도록.
정해 둔 규칙과 사람의 승인을 분리합니다.

02 · 필요한 만큼만

반복 호출에 경계선

연결된 요청의 횟수와 추정 예산을 제한합니다.
공급자의 자체 한도도 함께 사용합니다.

03 · 숨기지 않는 범위

안 되는 것도 분명하게

무엇을 검사했고 무엇을 놓칠 수 있는지.
‘보호 중’이라는 착각을 만들지 않습니다.

기능 설명 미리보기

어떤 때 멈추게 될까요?

미리 정한 예시의 규칙 판정을 보여줍니다. 실제 명령·파일·결제·AI 계정에는 연결하지 않습니다.

차단하는 예시

중요 폴더를 지우려는 요청

삭제처럼 되돌리기 어려운 명령은 자동으로 진행하지 않도록 막습니다. 현재 시제품은 연결된 도구의 요청만 검사합니다.

고정된 설명 예시이며 실시간 보안 진단이나 실제 피해 예방 결과가 아닙니다.

첫 번째로 만드는 것

  • 로컬에서 동작하는 행동 검사 규칙
  • 지원 AI 도구의 실행 전 검사 연결기
  • 텍스트 AI 호출의 반복·추정 비용 제한
  • 이유와 보호 범위를 보여 주는 한국어 화면

아직 약속할 수 없는 것

  • 전체 컴퓨터의 모든 해킹·악성코드 차단
  • 모든 AI·결제·메일 서비스 자동 보호
  • 기존 AI 구독의 무조건적인 무료 연동
  • 완전한 안전·반드시 절감되는 비용
현재는 로컬 알파 단계입니다.
정식 판매, 보안 인증, 실제 AI 도구와의 종합 실사용 검증은 완료되지 않았습니다. API 비용을 직접 부담하는 개인 자동화 이용자부터 작게 검증하려고 합니다. 가격과 출시일은 확정하지 않았습니다. 이 페이지는 회원가입·결제·API 키·개인정보를 요청하지 않습니다.
AI 브레이크 · 사람이 정한 경계선. 규칙이 먼저, AI는 보조.
이 페이지 자체에는 외부 AI 호출·분석 추적기·입력정보 수집 코드가 없습니다. 공개 호스팅 시 접속기록 처리는 호스팅 서비스 정책을 별도로 확인해야 합니다.
